# 部署

下文 `<部署根>` 指放代码和缓存的宿主目录，`<数据根>` 指图片所在的宿主目录，`<镜像>` 是任意带 python3 + Pillow 的镜像。

## Docker

```bash
docker run -d --name imagewall --restart unless-stopped --network host --memory 1200m \
  -e IMG_DATA_ROOT=/data -e IMG_ROOTS=图片:漫画:素材 -e IMG_CACHE=/cache \
  -v <数据根>:/data:ro -v <部署根>/cache:/cache -v <部署根>/app:/app:ro \
  --entrypoint python3 <镜像> /app/server.py --port 8899
```

- `--network host`：否则局域网里的手机 / 电脑访问不到容器
- 挂载必须写**宿主路径**，docker daemon 不认容器内路径
- 数据只读挂载就够，缓存目录要可写

## 改代码后

| 改了什么 | 怎么生效 |
|-|-|
| `index.html` / `static/` 下的文件 | 直接覆盖，浏览器刷新即可（静态文件是 `no-cache` + ETag） |
| `server.py` | 必须 `docker restart imagewall` |

## nginx 反代

页面里的 URL 全是相对路径，挂在子路径下也能用：

```nginx
location = /wall { return 301 /wall/; }
location /wall/ {
    proxy_pass http://127.0.0.1:8899/;
    proxy_http_version 1.1;
    proxy_set_header Connection "";
    proxy_read_timeout 120s;
}
```

**不要加 `proxy_buffering off`**：大 JSON 清单经 nginx 会间歇 504。

外网访问前在 nginx 层加 `auth_basic`，或放在带访问控制的隧道后面；应用自身没有账号系统。

## 从原型升级

v1.0 的缓存键里加了规格和格式，原型生成的缩略图不会再被命中。它们的文件名格式和新的一样（`<2 位>/<38 位>.jpg`），
超过缓存上限时会按最久未访问被正常清掉。想立刻腾空间可以整体删掉缓存目录。

设置从原型的 `wall.settings.v1` 自动迁移（缩略图长边 → 清晰度档位）。
